What survives which guardrail we can't see

Eight independently-plausible hypotheses (G0–G7) about how a stricter, held-out private guardrail might differ from the public one — measured, not guessed, by running each attack's real candidate payloads through each proxy's decide() (§6.1–§6.6). G1/G3 deny every EXFILTRATION-based attack by construction (they inspect the payload/intent an exfil marker must pass through) — the two columns that motivated building a mechanism that isn't EXFILTRATION at all.
